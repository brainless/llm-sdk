# Create a chat completion

POST https://models.mixlayer.ai/v1/chat/completions
Content-Type: application/json

Generate a chat completion from one of the available models. Mixlayer’s API is OpenAI-compatible, so existing OpenAI client libraries work without modification — see [Client Libraries](/client-libraries) for examples.

Set `stream` to true to receive JSON chunks as server-sent events; the stream ends with `data: [DONE]`.

Reference: https://docs.mixlayer.com/api-reference/inference-ap-is/chat-completions/chat-completions

## Authentication

- `Authorization` header (bearer token, required) — Mixlayer API key or console user session supplied as a Bearer token.

## Request

### Body (application/json)

- `messages` (list of object or object or object or object, required) — Message objects in turn order. Each message has a `role` and `content`.
  - object
    - `content` (string or list of object or object or object, required) — System message content.
    - `role` (enum, required)
      - Allowed values: `system`
  - object
    - `content` (string or list of object or object or object, required) — User message content.
    - `role` (enum, required)
      - Allowed values: `user`
  - object
    - `role` (enum, required)
      - Allowed values: `assistant`
    - `content` (string or list of object or object or object, optional, nullable)
    - `reasoning_content` (string, optional, nullable) — Reasoning content returned by a reasoning model.
    - `tool_calls` (list of object, optional, nullable) — Tool calls requested by the assistant.
      - `function` (object, required) — Function call generated by the model.
        - `arguments` (string, required) — Function arguments serialized as JSON.
        - `name` (string, required) — Name of the function to call.
      - `id` (string, required) — Tool call identifier.
      - `type` (string, required) — Tool type, always `function`.
      - `index` (integer, optional) — Index of this tool call.
  - object
    - `content` (string or list of object or object or object, required) — Tool result content.
    - `role` (enum, required)
      - Allowed values: `tool`
    - `tool_call_id` (string, required) — Tool call being answered.
- `model` (string, required) — Model identifier.
- `web_search_options` (object, optional, nullable) — Chat Completions request shape for hosted web search.
  - `category` (enum, optional, nullable) — Exa content category accepted by the public web-search options.
    - Allowed values: `company`, `people`, `research paper`, `news`, `personal site`, `financial report`
  - `filters` (object, optional, nullable) — Domain allow/block filters for hosted web search.
    - `allowed_domains` (list of string, optional)
    - `blocked_domains` (list of string, optional)
  - `max_characters` (integer, optional)
  - `max_results` (integer, optional)
  - `user_location` (object, optional, nullable) — Chat Completions wrapper for an approximate user location.
    - `approximate` (object, required) — Optional approximate-location fields shared by Chat requests.
      - `city` (string, optional, nullable)
      - `country` (string, optional, nullable)
      - `region` (string, optional, nullable)
      - `timezone` (string, optional, nullable)
    - `type` (string, required)
- `frequency_penalty` (float, optional, nullable) — Penalizes tokens proportional to how often they have appeared. Positive values reduce repetition.
- `max_completion_tokens` (integer, optional, nullable) — Maximum tokens to generate. Takes precedence over `max_tokens`.
- `max_tokens` (integer, optional, nullable) — Legacy alias for `max_completion_tokens`.
- `metadata` (any, optional) — Developer-supplied metadata stored with the response when `store` is true.
- `presence_penalty` (float, optional, nullable) — Penalizes tokens that have appeared at all. Positive values encourage topical novelty.
- `reasoning_effort` (string, optional, nullable) — Reasoning effort: `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, or `max`.
- `repetition_penalty` (float, optional, nullable) — Multiplicative penalty on tokens already in the context. `1.0` applies no penalty.
- `response_format` (object, optional, nullable)
  - `type` (enum, required) — Output format: `text`, `json_object`, or `json_schema`.
    - Allowed values: `text`, `json_object`, `json_schema`
  - `json_schema` (object, optional, nullable)
    - `schema` (any, optional) — JSON Schema the model output must match.
    - `strict` (boolean, optional, nullable) — Whether the schema is enforced strictly. Defaults to true.
- `seed` (long, optional, nullable) — Best-effort deterministic sampling seed.
- `stop` (list of string, optional, nullable) — Sequences that halt generation. The stop sequence is not included in the output.
- `store` (boolean, optional, default: false) — Persist the completed request and response for later use.
- `stream` (boolean, optional, default: false) — If `true`, stream the response as Server-Sent Events. Defaults to `false`.
- `stream_options` (object, optional, nullable)
  - `include_obfuscation` (boolean, optional, nullable) — Accepted for OpenAI compatibility; obfuscation is not added by the gateway.
  - `include_usage` (boolean, optional, default: false) — Include a final usage-only chunk before the `[DONE]` event.
- `temperature` (float, optional, nullable) — Controls randomness. Lower values make output more deterministic; higher values make it more diverse.
- `thinking` (boolean, optional, nullable) — Legacy boolean reasoning switch accepted as `thinking` or `reasoning`.
- `tools` (list of object, optional, nullable) — Function tools the model may call.
  - `function` (object, required) — Function definition invoked by the model.
    - `description` (string, required) — Description of what the function does.
    - `name` (string, required) — Function name. Must contain only letters, digits, underscores, or hyphens and be at most 64 characters.
    - `parameters` (any, required) — JSON Schema describing the function arguments.
    - `strict` (boolean, optional, nullable) — Whether generated arguments must strictly match the schema.
  - `type` (enum, required) — Tool type. Currently only `function` is supported.
    - Allowed values: `function`
- `top_k` (integer, optional, nullable) — Only consider the top-`k` most likely tokens at each step.
- `top_p` (float, optional, nullable) — Only consider tokens whose cumulative probability is below this value.

## Response

### 200

A complete response or a stream of completion chunks, selected by the request's `stream` field

- `choices` (list of object, required) — Generated completion choices.
  - `index` (integer, required) — Index of this choice in the response.
  - `message` (object, required) — Generated assistant message.
    - `content` (string, required) — Generated assistant text.
    - `role` (enum, required) — Message author role, always `assistant`.
      - Allowed values: `assistant`
    - `reasoning_content` (string, optional, nullable) — Reasoning content supplied by or returned from a reasoning model.
    - `sources` (list of object, optional, nullable)
      - `title` (string, required)
      - `url` (string, required)
    - `tool_calls` (list of object, optional, nullable) — Tool calls requested by an assistant message.
      - `function` (object, required) — Function call generated by the model.
        - `arguments` (string, required) — Function arguments serialized as JSON.
        - `name` (string, required) — Name of the function to call.
      - `id` (string, required) — Tool call identifier.
      - `type` (string, required) — Tool type, always `function`.
      - `index` (integer, optional) — Index of this tool call.
  - `finish_reason` (string, optional, nullable) — Why generation stopped: `stop` or `tool_calls`.
- `created` (long, required) — Unix timestamp when the completion was created.
- `id` (string, required) — Unique identifier for the chat completion.
- `model` (string, required) — Model used to generate the completion.
- `object` (enum, required) — Object type, always `chat.completion`.
  - Allowed values: `chat.completion`
- `usage` (object, required) — Token usage for the request.
  - `completion_tokens` (integer, required) — Number of generated tokens.
  - `prompt_tokens` (integer, required) — Number of input tokens.
  - `prompt_tokens_details` (object, required) — Detailed input-token usage.
    - `audio_tokens` (integer, required) — Number of audio input tokens.
    - `cached_tokens` (integer, required) — Number of cached input tokens.
  - `total_tokens` (integer, required) — Total input and generated tokens.
  - `server_tool_use` (map from string to long, optional)

	req, _ := http.NewRequest("POST", url, payload)

	req.Header.Add("Authorization", "Bearer <token>")
	req.Header.Add("Content-Type", "application/json")

	res, _ := http.DefaultClient.Do(req)

	defer res.Body.Close()
	body, _ := io.ReadAll(res.Body)

	fmt.Println(string(body))

}
